# StudySphere

StudySphere is a modern Flutter prototype for an AI-powered studying and productivity app.

## Features included
- Material 3 themed UI with purple-blue gradients
- Home dashboard for tasks, streaks, and focus stats
- AI coach, group, and planner sections
- Pomodoro-style study actions

## Run locally
1. Install Flutter SDK.
2. From this folder, run:
   - `flutter pub get`
   - `flutter run`
